# Coding Guidelines

本プロジェクトのコーディング規約をまとめる。

## 全般

- ビルドツール・パッケージマネージャー・リンター・フォーマッターは使用しない
- 外部ライブラリに依存しない（vanilla JS / CSS のみ）
- インデントはスペース 2 つ
- UI テキスト・コメントは日本語で記述する

## JavaScript

### 変数宣言

- `var` は使用しない
- 再代入しない変数は `const`、再代入する変数は `let` で宣言する
- DOM 要素の取得はファイル先頭でまとめて行う

### 関数定義

- すべての関数はアロー関数で定義し、`const` に代入する

```js
const functionName = () => {
  // ...
};
```

### 命名規則

- 変数・関数名は camelCase を使用する
- DOM 要素の変数名には用途を示すサフィックスを付ける
  - `Lbl` — テキスト表示用の `<span>` / `<p>`（例: `minutesLbl`, `statusLbl`）
  - `Btn` — `<button>`（例: `startBtn`, `stopBtn`）
  - `Field` — `<input>`（例: `limitField`）
  - `Par` — `<p>`（例: `timerPar`）
- 配列変数名には `Array` または `List` サフィックスを付ける（例: `minPassArray`, `wrapList`）
- DOM 要素変数以外の配列は複数形も可（例: `minutes`）

### 文字列

- 文字列リテラルにはダブルクォート `"` を使用する
- 式の埋め込みが必要な場合はテンプレートリテラル `` ` `` を使用する

### 比較演算子

- 等値比較には `===` / `!==` を使用する（`==` / `!=` は使用しない）

### コメント

- `//` スタイルのコメントを使用する
- コメントは日本語で記述する
- JSDoc は使用しない

### イベントリスナー

- `window` の `load` イベント内で初期設定とイベントリスナーの登録を行う
- `addEventListener` の第 3 引数には `false` を明示する

### その他

- セミコロンは省略しない
- 末尾カンマは付けない（ただしオブジェクトリテラルの最終プロパティ後には付けてもよい）

## HTML

### 構造

- `<section>` で大きなブロックを区切り、`id` 属性でセクションを識別する
- スクリプトの読み込みには `defer` 属性を使用する

### 命名規則

- `id` 属性は camelCase を使用する（例: `limitField`, `minutesPass1`, `wrapWrapper`）
- `class` 属性は snake_case を使用する（例: `wrap_item`）

### 属性

- 属性値にはダブルクォート `"` を使用する

## CSS

### セレクター

- 要素型を明示するセレクターを使用する（例: `section#main`, `p#status`, `li.wrap_item`）

### 色

- 色の指定には 16 進数カラーコードを使用する（例: `#263238`, `#fafafa`）
- 透過が必要な場合は `rgba()` を使用する

### 単位

- 固定サイズには `px` を使用する
- フォントサイズなど相対的なサイズには `px` を基本とし、ボタンの padding など要素相対の場合は `em` を使用する
- ビューポート相対のサイズには `%` または `vh` を使用する

### その他

- CSS カスタムプロパティ（CSS 変数）やプリプロセッサは使用しない
- プロパティの末尾にはセミコロンを付ける
